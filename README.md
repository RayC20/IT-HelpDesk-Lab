# Linux IT Help Desk Lab

## Overview
This project is a hands-on IT help desk lab that I built using Ubuntu Server, Docker, osTicket, and MariaDB. The goal was to practice deploying and using a ticketing system while gaining experience with Linux server administration and troubleshooting.

## Technologies Used
- Ubuntu Server
- VMware Workstation
- Docker
- Docker Compose
- osTicket
- MariaDB
- Linux Command Line

## What I Did
- Created and configured an Ubuntu Server virtual machine
- Installed and configured Docker
- Deployed osTicket and MariaDB using Docker Compose
- Configured the database connection for osTicket
- Verified container and web service connectivity
- Accessed and managed the osTicket staff portal
- Claimed and managed a support ticket
- Responded to and resolved a support ticket
- Closed the completed ticket
- Troubleshot configuration and connectivity issues during deployment

## Skills Demonstrated
- Linux Administration
- Docker & Container Management
- Help Desk Ticketing Systems
- IT Troubleshooting
- MariaDB
- Basic Server Administration
- Virtual Machines
- Technical Support
